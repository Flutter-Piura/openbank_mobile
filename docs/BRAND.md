# Identidad visual de OpenBank

## Marca

![Marca de OpenBank](assets/openbank-mark.png)

La marca combina tres conceptos:

- un contorno abierto que representa interoperabilidad y comunidad;
- una institución financiera simplificada;
- un espacio central protegido que comunica confianza.

## Paleta

| Token | Color | Uso |
| --- | --- | --- |
| Navy | #102A43 | Confianza, texto y superficies principales |
| Emerald | #00A878 | Apertura, acción y estados positivos |
| Surface | #F7FAFC | Fondos claros de la aplicación |

Los colores coinciden con los tokens definidos en
[openbank_theme.dart](../lib/app/openbank_theme.dart).

## Uso

- Conserva espacio libre alrededor de la marca.
- No deformes, gires ni añadas sombras.
- No alteres la proporción entre sus elementos.
- Usa el archivo PNG con transparencia sobre fondos de alto contraste.
- Mantén el nombre OpenBank como texto accesible junto a la marca cuando el
  contexto lo permita.

## Archivo maestro

El recurso versionado es
[openbank-mark.png](assets/openbank-mark.png), un PNG RGBA de 640 × 640
píxeles. Se creó como una marca original para este proyecto y se distribuye
bajo la misma licencia MIT del repositorio.

## Especificación de generación

~~~text
Use case: logo-brand
Asset type: primary open-source project logo mark for GitHub README and mobile
banking app
Primary request: create an original geometric symbol for OpenBank, an
educational open-source banking platform built by Flutter Piura. Combine
subtly an open doorway or bracket, a bank building and the letter O.
Style: vector-friendly, flat, minimal and professional fintech identity.
Colors: deep navy #102A43 and emerald green #00A878.
Constraints: transparent background, no text, no mockup, no 3D, no shadows,
no watermark and readable at 32 px.
~~~
